This project is my automated crane code for microbit gigo

Hardware
- microbit
- GIGO blocks
- GIGO servo
- GIGO motor
- GIGO botton

> Open this page at [https://shoyaa0815.github.io/automated_crane/](https://shoyaa0815.github.io/automated_crane/)

## Use as Extension

This repository can be added as an **extension** in MakeCode.

* open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* click on **New Project**
* click on **Extensions** under the gearwheel menu
* search for **https://github.com/shoyaa0815/automated_crane** and import

## Edit this project

To edit this repository in MakeCode.

* open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* click on **Import** then click on **Import URL**
* paste **https://github.com/shoyaa0815/automated_crane** and click import
